# TUKE OZ — Tabular Playground Series Jul 2022

Початковий етап семестрового завдання: Data Understanding / EDA за CRISP-DM.
Задача — **unsupervised clustering**, без відомої цільової колонки.
Код не створює міток класів і не підміняє кластеризацію класифікацією.
Вимоги до класифікаційних метрик із загального завдання слід узгодити з викладачем для цього датасету.

## Що перевіряємо

Форму, типи, пропуски (кількість і відсоток), унікальні значення,
повні дублікати та дублікати без колонки `id`, сталі колонки й описову статистику.
`id` — лише кандидат на ідентифікатор; його роль потрібно підтвердити перед моделюванням.
На цьому етапі не видаляємо рядки, не заповнюємо пропуски й не масштабуємо ознаки.

Результати: `summary.json` (зокрема SHA-256 джерела та версії Python/pandas),
`column_profile.csv`, `descriptive_statistics.csv`, `preview.csv` (перші 10 рядків)
та `numeric_statistics.csv`, якщо є числові колонки.
Кількість дублікатів означає повторні рядки після першого входження (`keep='first'`).
Повторний запуск перезаписує однойменні звіти; для різних наборів даних використовуй окремий `--output`.
Звіти з'являться лише після успішного читання CSV. Без файлу буде зрозуміле повідомлення з потрібним шляхом.

## Наступні етапи

Після реального EDA: визначити ознаки, обґрунтувати очищення й масштабування,
порівняти K-Means та Gaussian Mixture, підібрати параметри,
оцінити структуру кластерів і підготувати документацію за CRISP-DM.
Поточна структура — початок роботи, а не завершене семестрове завдання.

## Етап 02 — підготовка даних

Відкрий `notebooks/02_preprocessing.ipynb` і виконай всі клітинки або запусти
`python src/preprocessing.py` із середовища зі встановленими залежностями.
Графіки, профілі, кореляції й перевірки: `reports/preprocessing/`.
Матриця, ID та порядок ознак: `data/processed/numeric_standardized.npz`.
Параметри StandardScaler: `data/processed/scaler_parameters.json`.

Це числовий baseline: 29 ознак без id. Семантика цілочисельних ознак ще не
підтверджена; трактування їх як числових відстаней є припущенням.
Рядки не видаляються, хвости за правилом IQR лише позначаються.
Scaler навчено на всіх рядках для трансдуктивної кластеризації. Для незалежної
оцінки на відкладених даних необхідно повторно fit тільки на тренувальній частині.
Повторний запуск перезаписує результати етапу 02. Сирий CSV не змінюється.
